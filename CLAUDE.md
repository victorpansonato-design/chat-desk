# Claude Code

Leia `AGENTS.md` e `prompt.md`. Este repositório foi preparado para você criar o produto localmente; os arquivos atuais são planejamento e evidências, não um aplicativo pronto.

Comece pela evidência e pelo estado real do repositório. Conserve escopo, explicite hipóteses e entregue uma única experiência responsiva nos três canais. Não pare em uma homepage bonita: valide histórico, conversa, anexos, áudio, atendimento humano, avaliação e encerramento conforme os estados descritos.

Não instale Craft Anything por padrão. Não espere uma integração real para construir mocks revisáveis. Conclua a rodada com execução local, verificações e pendências honestas.
